# Doppelkopf

Doppelkopf online für 1–4 Menschen, freie Plätze übernehmen Computergegner (Hilde, Knut, Professor). Läuft im Browser und lässt sich auf Smartphone und Desktop als App (PWA) installieren.

**Spielen:** https://doppelkopf.apps.diefranks.eu

- Regeln nach DDV-Turnierspielregeln, mit oder ohne Neunen: Hochzeit, stille Hochzeit, Damen-, Buben-, Farb- und Fleischlos-Solo, Re/Kontra und Absagen, Fuchs, Doppelkopf, Karlchen
- Partie über 4–24 Runden, Spielstand auf dem Bierdeckel
- Einladungslink für Mitspieler, Wiederverbinden nach dem Neuladen

Entwicklung: siehe [CLAUDE.md](CLAUDE.md), Betrieb: [deploy/README.md](deploy/README.md), Spezifikation: `openspec/specs/`.
